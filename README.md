# Аркхэм на двоих

Кооперативный детектив в духе Лавкрафта для двух игроков с ИИ-ведущим. Дело № 1 «Тихая нота», около 15 минут.

- Статический сайт, сборка не нужна: `index.html`, `style.css`, `engine.js` (дело, правила, состояние, промпты), `app.js` (интерфейс, звук, синхронизация).
- Ведущий: Qwen через OpenRouter, ключ вводит тот, кто создаёт стол (хранится в его браузере).
- Синхронизация двух устройств: публичный сервис ntfy.sh, комната — случайное имя темы в ссылке.
- Режим «на одном экране» работает без синхронизации.
- Иллюстрации в `img/` сгенерированы моделью Gemini Flash Image через OpenRouter.

Локально: `python3 -m http.server -d docs 8000` и открыть http://localhost:8000.
